# Tubase

TubaseはWindows向けのローカル完結型DAWの最初の動作版です。WAVを複数トラックに配置し、再生、トラック音量・パン調整、クリップ移動・トリム、プロジェクト保存、ステレオWAV書き出しができます。

## 開発状況

このリポジトリは空の状態から開始しました。既存コードや設定ファイルはありませんでした。

調査計画ではC++20/JUCEを第一候補としていましたが、この作業環境にはCMakeとVisual Studio C++コンパイラーがなく、JUCEのAGPLv3／商用ライセンス方針も未決定でした。初版をすぐビルドして動かすため、インストール済みの.NET 10とWPFを使い、外部NuGetパッケージに依存しない構成にしています。音声出力はWindowsのwaveOut APIを使います。これは最小版の判断であり、計画書のC++/JUCE案を最終決定したものではありません。

## 実装済み機能

- WAV PCM 8/16/24/32-bitとIEEE float 32-bitの読み込み
- 一般的なWAVE_FORMAT_EXTENSIBLE PCM／IEEE float WAVの読み込み
- 複数のオーディオトラックとWAVクリップ
- WAV素材をプロジェクトのAudioフォルダへコピーして取り込み
- タイムライン上でクリップをドラッグして移動
- クリップ右端をドラッグして長さを短縮・延長
- トラックごとのミュート、音量、左右パン
- Windows既定のオーディオ出力で再生・停止
- ローカルプロジェクトの保存・再読み込み
- 44.1 kHz、ステレオ、16-bit PCM WAVへのオフライン書き出し
- 一時ファイルを使ったプロジェクトJSONの保存
- WAV読込、トラックミックス、プロジェクト保存・読込、WAV出力のスモークテスト

### WAVインポートの修正

Import WAVは選択ファイルをフルパスで扱い、プロジェクト内へコピーする前にデコードと形式検証を行います。複数ファイルを選ぶと、選択中のトラックから1ファイルずつ別トラックに配置します。問題のあるファイルはクリップ登録せず、読み込み済みの他ファイルは保持します。失敗したファイル名と例外理由を画面に表示し、`%LOCALAPPDATA%\Tubase\Logs\import.log`にも記録します。

PCM/IEEE float以外の圧縮形式、破損したRIFFチャンク、対応外のビット深度などは明確なエラーになります。今回の利用者環境で失敗した元WAVファイルは提供されていないため、そのファイル固有の形式が直接原因だったかは特定できていません。修正版の自動テストでは合成したPCM16 WAVを2件インポートし、別トラック登録、保存・再読み込み、ミックス可能な音声データ、無効ファイルのエラー報告を確認しています。

プロジェクトはフォルダ形式です。フォルダ内のproject.jsonがトラックやクリップを記録し、Audioには取り込んだWAV、Peaksには今後の波形キャッシュ、Autosavesには今後の自動保存を置く想定です。現在はPeaksとAutosavesの自動生成機能はまだありません。

## 必要環境

- Windows 10/11
- .NET 10 SDK
- Windows Desktop Runtime 10（SDK導入済みなら通常含まれます）

## ビルドと起動

リポジトリのルートで実行します。

    dotnet build Tubase.csproj -c Release

ビルドしたアプリを起動します。

    .\bin\Release\net10.0-windows\Tubase.exe

Visual Studioから開く場合はTubase.csprojを開いて実行します。初回起動後にNew Projectで空のプロジェクトフォルダを選び、Import WAVから素材を読み込みます。

## 基本操作

1. New Projectを押してプロジェクト用フォルダを選択します。既存ファイルは削除しません。
2. Import WAVで1つ以上のWAVを選びます。素材はプロジェクト内へコピーされます。
3. 必要に応じてAdd Trackでトラックを追加し、行を選択してからImport WAVを使います。読み込んだクリップは再生位置に追加されます。
4. クリップ本体を左右へドラッグして開始位置を変更します。右端のつまみを左右へドラッグして長さを調整します。
5. 各トラックのVolume、Pan、Mボタンで音量、パン、ミュートを調整します。Panは中央で左右同量、端で反対側を減衰させます。
6. タイムラインの空白をクリックして再生位置を変更し、Playで再生、Stopで先頭へ戻します。Zoomで時間軸の拡大率を変更します。
7. Saveで保存します。次回はOpenからプロジェクト内のproject.jsonを選びます。
8. Export WAVで曲全体をステレオWAVに書き出します。

## 制限事項

- 現在はWindowsのみです。オーディオ出力先はWindowsの既定デバイスで、デバイス選択、ASIO/WASAPI詳細設定、サンプルレート・バッファー設定UIはありません。
- 大きなWAVは全体をメモリへ読み込みます。巨大ファイルや非常に多数のトラックではメモリを多く使います。
- 読み込みはモノラル／ステレオWAVのみです。3ch以上のWAV、MP3、AAC/M4A、FLAC、AIFF、Ogg、MIDIには未対応です。
- WAV書き出しは44.1 kHz、ステレオ、16-bit PCM固定で、ファイルサイズは4 GiB未満に制限しています。
- トラック音量は線形スライダー（0〜2倍）、パンはステレオバランス制御です。マスターエフェクト、フェーダー単位のdB表示、クリップフェードはありません。
- クリップ編集は移動と末尾トリムのみです。分割、波形プレビュー、Undo/Redo、スナップ、テンポグリッドはありません。
- 再生処理は簡易waveOutバッファ方式です。プロ向け低遅延・ドロップアウト保証はありません。操作中の実機再生負荷試験が必要です。
- 自動保存、録音、MIDI、VST3、オートメーション、プラグイン隔離は未実装です。
- プロジェクトの素材は取り込み時にコピーされます。書き出し時のクリッピング防止リミッターはありません。0 dBFSを超えるミックスは最大値でクリップします。
- ローカルブランチ名は開始時にmasterでした。GitHubの既定ブランチはmainです。初回コミット前にmainへ揃えることを推奨します。
