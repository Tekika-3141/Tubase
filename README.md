# Tubase

TubaseはWindows向けのローカル完結型DAWです。WAVを複数トラックに配置し、波形イベントを見ながら再生、トラック音量・パン調整、クリップ移動・トリム、Undo/Redo、プロジェクト保存、自動復旧、ステレオWAV書き出しができます。

## 開発状況

このリポジトリは空の状態から開始しました。既存コードや設定ファイルはありませんでした。

調査計画ではC++20/JUCEを第一候補としていましたが、この作業環境にはCMakeとVisual Studio C++コンパイラーがなく、JUCEのAGPLv3／商用ライセンス方針も未決定でした。初版をすぐビルドして動かすため、インストール済みの.NET 10とWPFを使い、外部NuGetパッケージに依存しない構成にしています。音声出力はWindowsのwaveOut APIを使います。これは最小版の判断であり、計画書のC++/JUCE案を最終決定したものではありません。

### WAVインポートの修正

Import WAVは選択ファイルをフルパスで扱い、プロジェクト内へコピーする前にデコードと形式検証を行います。複数ファイルを選ぶと、選択中のトラックから1ファイルずつ別トラックに配置します。問題のあるファイルはクリップ登録せず、読み込み済みの他ファイルは保持します。失敗したファイル名と例外理由を画面に表示し、`%LOCALAPPDATA%\Tubase\Logs\import.log`にも記録します。

PCM/IEEE float以外の圧縮形式、破損したRIFFチャンク、対応外のビット深度などは明確なエラーになります。今回の利用者環境で失敗した元WAVファイルは提供されていないため、そのファイル固有の形式が直接原因だったかは特定できていません。修正版の自動テストでは合成したPCM16 WAVを2件インポートし、別トラック登録、保存・再読み込み、ミックス可能な音声データ、無効ファイルのエラー報告を確認しています。

プロジェクトはフォルダ形式です。フォルダ内のproject.jsonがトラックやクリップを記録し、Audioには取り込んだWAV、Peaksには将来の波形キャッシュ、Autosavesには2分ごとの復旧スナップショットを置きます。マニフェスト保存は同じフォルダに一時JSONを書いて検証し、既存マニフェストをproject.json.bakへコピーしてから一時JSONをコピーし、保存後に再読込検証します。失敗時はバックアップから戻し、一時JSONのパスを含む例外を返します。破損したマニフェストをバックアップから開いた場合は、復旧コピーでマニフェストも修復します。Windowsの隔離環境では同一フォルダ内のリネーム操作が拒否されることがあるため、このコピー方式を使っています。コピーは単一の原子的な置換ではありませんが、前回保存をバックアップとして保持します。

## ビルドと起動

リポジトリのルートで実行します。

    dotnet build Tubase.csproj -c Release

ビルドしたアプリを起動します。

    .\bin\Release\net10.0-windows\Tubase.exe

Visual Studioから開く場合はTubase.csprojを開いて実行します。画面・ダイアログは日本語です。初回起動後に「新規」でプロジェクト用フォルダーを選び、「WAV読込」から素材を読み込みます。アプリアイコンは `Assets/Tubase.ico`、ベクター原稿は `Assets/Tubase.svg`、再生成スクリプトは `GenerateTubaseIcon.ps1` です。

### GitHubから取得したWindowsで実行する

`portable/win-x64/Tubase.exe` はWindows x64向けの自己完結型Releaseパッケージです。パッケージ一式をリポジトリに含めるため、別のWindows端末では.NET Desktop Runtimeを別途インストールせずに実行できます。GitHubへこのパッケージを含む変更がコミット・pushされた後にcloneまたはpullし、`portable\win-x64\Tubase.exe`を起動してください。開発環境でパッケージを再生成する場合はリポジトリルートで `.Publish-Windows.ps1` を実行します（再生成には.NET 10 SDKが必要です）。`.gitignore`は`bin/`、`obj/`と他のportable出力を無視し、配布用`portable/win-x64/`のみ追跡対象にします。

## 基本操作

1. 「新規」でプロジェクト用フォルダーを選択します。既存ファイルは削除しません。
2. 「WAV読込」で1つ以上のWAVを選びます。素材はプロジェクト内へコピーされます。
3. 必要に応じて「＋トラック」でトラックを追加し、行を選択してから読み込みます。読み込んだクリップは再生位置に追加されます。
4. クリップ本体をドラッグして開始位置を変更し、右端のつまみで長さを調整します。Deleteキーで選択中のクリップを削除できます。
5. トラックを選ぶと左Inspectorの音量フェーダー（0〜200%）とパン（左／中央／右）を操作できます。トラック欄の値表示も連動します。Mでミュート、×でトラック削除です。
6. タイムラインの空白をクリックして再生位置を変更し、再生／停止ボタンで再生、停止ボタンで先頭へ戻します。ズームで時間軸を調整します。スナップ有効時は位置を0.25秒単位に揃えます。
7. 「保存」で保存し、次回は「開く」からproject.jsonを選びます。
8. 「WAV書出」で曲全体をステレオWAVに書き出します。
9. Ctrl+Z / Ctrl+Yで編集を戻す／やり直す、Ctrl+Sで保存、Spaceで再生／一時停止します。保存済みプロジェクトを開いた際、より新しい復旧スナップショットがあれば復元できます。
10. ツールバーの「右ゾーン」で右側の領域を開閉し、境界をドラッグして幅を調整します。現在は空の領域案内のみで、メディアブラウザーやラック等の機能はありません。開閉でプロジェクトの編集状態は変わりません。

## 制限事項

- 現在はWindowsのみです。オーディオ出力先はWindowsの既定デバイスで、デバイス選択、ASIO/WASAPI詳細設定、サンプルレート・バッファー設定UIはありません。
- 大きなWAVは全体をメモリへ読み込みます。巨大ファイルや非常に多数のトラックではメモリを多く使います。
- 読み込みはモノラル／ステレオWAVのみです。3ch以上のWAV、MP3、AAC/M4A、FLAC、AIFF、Ogg、MIDIには未対応です。
- WAV書き出しは44.1 kHz、ステレオ、16-bit PCM固定で、ファイルサイズは4 GiB未満に制限しています。
- トラック音量は線形スライダー（0〜2倍）、パンはステレオバランス制御です。マスターエフェクト、フェーダー単位のdB表示、クリップフェードはありません。音量・パンの実際の聴感は出力機器で未検証です。
- クリップ編集は移動、末尾トリム、削除です。分割、テンポ／小節グリッド、MIDI、ピアノロール、Undoの編集履歴永続化はありません（Undo履歴はセッション中のみ）。
- 再生処理は簡易waveOutバッファ方式です。プロ向け低遅延・ドロップアウト保証はありません。操作中の実機再生負荷試験が必要です。
- 復旧スナップショット保存は実装済みですが、録音、MIDI、VST3、オートメーション、プラグイン隔離は未実装です。
- プロジェクトの素材は取り込み時にコピーされます。書き出し時のクリッピング防止リミッターはありません。0 dBFSを超えるミックスは最大値でクリップします。
- マニフェストはバックアップ付きコピーで更新します。保存後に検証し、失敗時は直前のproject.json.bakへ戻します。OS／電源の強制終了がファイルコピー中に起きた場合は完全な原子的保存ではないため、前回バックアップから読み込む設計です。
